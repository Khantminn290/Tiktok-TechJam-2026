Hypothesis      : A temporally causal user-by-author affinity feature should help within-user ranking because it varies across impressions for the same user, captures whether this user has recently tended to long-view content from this author, and is not recoverable from user/video/author embeddings alone when the same user is shown multiple authors in a session/day. Given the current best uses recency-weighted user history, this is a feature-level analogue focused on a higher-signal interaction likely aligned with long_view.
Mechanism       : For each impression, compute the user's exponentially recency-weighted historical long_view rate for that author using only earlier training impressions, with a backoff to the user's global recency-weighted long_view rate when author-specific history is sparse. Incremental     : Existing embeddings can model static user-author affinity only through learned latent interactions from training, but they do not expose a causal, time-varying state that changes across rows for the same user based on immediately preceding behavior.
